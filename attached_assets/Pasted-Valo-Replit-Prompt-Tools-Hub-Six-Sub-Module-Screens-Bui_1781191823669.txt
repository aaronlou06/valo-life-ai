Valo — Replit Prompt: Tools Hub + Six Sub-Module Screens

Build a Tools hub screen and six tool sub-module screens for the Valo app. The "Tools" option in CheckInSheet (the bottom sheet opened by the center + FAB) should navigate to this new hub. App root: artifacts/valo/ (Expo Router, React Native, TypeScript).

Step 4 — Six sub-module screens

Each screen follows the same base pattern: sand background, consistent header (back button + title), then its own content. All screens are functional placeholders with meaningful structure — not blank "coming soon" pages. Use real UI scaffolding so Valo feels alive, but no backend wiring is required; use static placeholder data.


4a. Accountability Buddy (accountability.tsx)

Purpose: Track commitments the user makes to themselves. AI-assisted accountability nudges (UI only for now).

Sections:


Active Commitments — A vertical list of commitment cards. Each card shows:

Commitment text (e.g., "Work out 4x this week")
Due date badge
Status pill: In Progress / Done / Overdue (terracotta for overdue, sage for done, amber for in progress)
Seed 2–3 placeholder commitments



Add Commitment — A tappable row at the bottom of the list (+ Add a commitment) that opens a simple TextInput inline form (commitment text + due date picker). Tapping "Save" appends to the list (in-memory state, no persistence needed).
Valo Nudge banner at top — a soft terracotta-tinted card with copy: "You've completed 2 of 5 commitments this week. Keep going." — static placeholder.



4b. Time Management (time-management.tsx)

Purpose: Day-level time blocking and focus session launcher.

Sections:


Today's Blocks — A vertical timeline list showing hourly slots from 7am–10pm. Pre-seed 2–3 placeholder blocks (e.g., "Deep Work — 9am–11am", "Lunch — 12pm–1pm") rendered as colored bars inline in the timeline. Blocks use slate blue #5B7FA6 fill at 20% opacity with a left 3px solid accent.
Focus Session — A card below the timeline with a large timer display (25:00), a "Start Focus" button (terracotta fill, white text, 12px radius), and a small "Customize" link. Timer is UI-only (no actual countdown needed).
+ Add Block — Tappable row that opens an inline mini-form: label, start time, end time. Appends to the list in component state.



4c. Fitness Planner (fitness.tsx)

Purpose: Weekly workout plan view with per-day workout cards.

Sections:


Week strip — 7 horizontal day pills (Mon–Sun). Active day highlighted in sage green #6B9E78. Tapping a pill switches the view to that day.
Day's Workout — Below the strip, show the planned workout for the selected day. For the active day (seed as "Tuesday"), show a workout card:

Workout name: "Push Day — Upper Body"
Tag pills: Strength · 45 min · Gym
Exercise list: 4–5 rows each showing exercise name, sets × reps (e.g., "Bench Press — 4×8"). Alternate white / subtle gray rows.



Rest days — Other days show a quiet "Rest day" card with a small moon icon.
+ Add Workout at bottom — tappable, opens inline form: name, type, duration. Appends to selected day in state.



4d. Meal Planner (meal-plan.tsx)

Purpose: Weekly meal plan grid with per-day meal slots.

Sections:


Week strip — same pattern as Fitness (Mon–Sun pills, terracotta active state).
Meal slots for selected day — Three rows: Breakfast, Lunch, Dinner. Each row shows:

Meal slot label (bold, 13px)
Meal name if assigned (e.g., "Greek yogurt + granola") or a faint "+ Add meal" tappable placeholder
Macro summary badge (e.g., "420 kcal" — static placeholder text)



Seeded data: Tuesday Breakfast = "Greek yogurt + granola · 420 kcal", Lunch = "Chicken rice bowl · 650 kcal", Dinner = empty.
Tapping "+ Add meal" opens an inline input for the meal name. Saves to state.
Weekly summary bar below the day view — a horizontal pill strip showing total kcal for each day of the week (static placeholder numbers). Acts as a quick nutrition overview.



4e. Grocery List (grocery.tsx)

Purpose: A running, categorized shopping list.

Sections:


Category groups — The list is grouped by category. Seed with three categories and items:

Produce: Spinach, Bananas, Bell peppers
Protein: Chicken breast, Greek yogurt, Eggs
Pantry: Brown rice, Olive oil, Oats



Each item row:

Checkbox (tapping toggles a strikethrough + gray out)
Item name (14px)
Optional quantity label (muted, right-aligned, e.g., "2 lbs")



Checked items stay visible but de-emphasized; a "Clear checked" button appears at top-right when any item is checked.
+ Add Item at the bottom — inline input with item name + category selector (dropdown among existing categories + "New category"). Appends to list in state.
Category headers use warm brown #A67C5B accent, 11px uppercase label.



4f. Progress Charts (charts.tsx)

Purpose: Visualize trends from Valo's tracked data.

Sections:


Time range selector — 4 pills at top: 7D · 1M · 3M · 6M. Active pill filled lavender #9B7BB8, others outlined. Switching range updates chart labels (use static data sets per range).
Chart cards — a vertical stack of chart cards, one per metric. Each card:

Metric title (14px semibold)
Trend badge (e.g., "↑ 12% vs last period" in sage green, or "↓ 5%" in a muted red)
A simple SVG line chart drawn with React Native's react-native-svg (if available) or a pure-RN bar chart using View blocks. Use placeholder data points — 7 points for 7D, 4 for 1M, etc.
Card height ~160px



Seed three chart cards:

Mood Score — scale 1–10, lavender line
Sleep (hrs) — scale 0–10, slate blue line
Habit Completion % — scale 0–100, sage green bars



If react-native-svg is not installed, use View-based bar charts (a row of proportionally-sized colored rectangles with labels beneath). Do not import a charting library that isn't already in the project's package.json.

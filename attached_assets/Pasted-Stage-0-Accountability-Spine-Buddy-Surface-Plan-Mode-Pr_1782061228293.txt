Then plan the Stage 0 build (spine + buddy), covering:


Shared-commitment spine (coach-agnostic).

A commitment a user opts into accountability for, referencing or extending the existing habit/goal model, with a cadence and a metric type (binary check / count / streak).
A participant + visibility model: a commitment can be shared with a participant at a chosen scope (e.g. streak-only vs. full detail). The user always sees exactly what is shared. Sharing is explicit and instantly revocable.
Explicitly confirm the participant model generalizes from {buddy} to {AI coach, human coach} with no structural change, and call out anything that would not.



Buddy relationship. Invite and accept via a shareable code or link (there is no social login — email/password only), with pending / active / blocked states.
Encouragement. A single model that holds a "support" cheer now and preset messages plus free-text chat later. Build the model to carry all three types; surface only the support button this stage.
Status exceptions. A structured exception on a commitment — pause / excused-absence / heads-up — with a window, a scope (one / several / all of a user's commitments), a visibility that reuses the share scope, and an optional note. Manual entry only this stage; calendar-inferred proposals come with the coach. Handle these behaviors:

A pause freezes and holds a streak: missed days inside the window neither break the streak nor fake-advance it.
For cadence commitments ("3×/week"), the window's target is waived rather than counted as a miss.
Forward-declared exceptions are clean; retroactive ones are allowed but shown to the buddy as retroactive — history is never silently rewritten.



The accountability page shell. A "your buddies" section listing each buddy's shared commitment(s) with a glanceable on-track / slipping / away status and a per-buddy support button; an empty/invite state; and an activity feed of recent encouragements and status events. Leave a clearly-marked placeholder where the AI coach section will mount in the next pass.

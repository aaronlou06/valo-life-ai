Build a mobile app called Valo — a personal AI life companion that helps users understand how their daily habits, mood, and lifestyle choices connect and affect each other. The core philosophy is that nothing in a person's life exists in isolation.
Build this in React Native with Expo. The app needs five main navigation tabs: Today, Voice, Goals, Insights, and Log.
Today tab: Shows a greeting with the user's name and the date. Displays three metric tiles at the top pulling from logged data: sleep hours, HRV (manual entry for now), and steps (manual entry for now). Below that shows three pillar score cards with a progress bar each — Health, Work/Mission, and Relationships — each showing a score out of 10 and a one-line status. At the bottom a prominent button that says "Start evening debrief."
Voice tab: A large microphone button in the center. Below it shows what Valo will ask about tonight based on the user's goals. Below that shows four quick-log buttons: Mood, Water, Wind down, Quick note.
Goals tab: Shows two sections — Big Goals (with title, target date, and a progress bar showing percentage complete) and Daily Habits (each with a name, current streak, and today's completion status as a checkmark).
Insights tab: Shows a 7-day mood chart as a simple bar chart. Below that shows AI-generated insight cards — each with a label, a 2-3 sentence insight in plain language, and an italic follow-up question in blue.
Log tab: Voice log button at the top. Below it a 2x3 grid of quick-log buttons: Workout, Meal photo, Focus session, Mood check, Water, Relationship. Below that shows today's log entries as a list with an icon, title, subtitle, and value for each.
Design: Clean, calm, minimal. Dark mode friendly. Use a soft off-white background, not pure white. No heavy charts or dashboards. Data should feel like insights from a thoughtful friend, not a clinical report. Use a consistent card-based layout throughout.
Start with user authentication so each user has their own account and data. Build a database to store: users, daily logs, mood entries, goals, habits, and insight entries. All data should be tied to the logged-in user.

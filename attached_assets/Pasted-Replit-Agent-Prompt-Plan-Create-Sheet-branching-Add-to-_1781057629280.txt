Replit Agent Prompt — Plan Create Sheet (branching "Add to plan" flow)
Goal
Build a new branching create sheet for the Plan page. When the user taps Add to plan and picks a kind, the sheet walks them through only the questions relevant to that kind — one step at a time, stacked on a single growing scrollable surface — instead of dumping every field at once. It must be guided but skippable: every revealed step comes pre-filled with a smart default and a Looks good → affordance so the common case is "type a title, hit Save."
This is the manual mirror of how Valo asks one thing at a time in voice. Event is the fully-detailed reference branch; build the other kinds to the same skeleton using the per-kind spec below.

Core interaction model (applies to every kind)

Step 0 — Kind picker (reuse existing). The existing "Add to plan" picker is the branch point: Event · Workout · Goal · Habit · Routine · Important date. Selecting a kind morphs the sheet into that kind's sequence.
Single growing sheet. Steps stack vertically on one scrollable surface. They do not hop between full modal screens.
Progressive reveal. Show one step at a time. The next step appears only after the current one is answered or skipped.
Smart defaults + skip-ahead. Each revealed step is pre-filled with a sensible default (the tapped day, the next open time slot, last-used facet, a 1h duration, annual recurrence, etc.) and shows a Looks good → control so the user can blow straight through.
Scroll back to edit. Any earlier answer remains visible and tappable to change.
Voice always one tap, never forced. The title field auto-focuses on open with an inline mic affordance.
Footer: primary Save (terracotta) + secondary Save & add another (terracotta text).


EVENT branch — reference implementation (build this one fully polished)
Steps, in order:

Title — auto-focused; inline mic affordance.
When — the heart of the flow. Render a visual day-timeline of the chosen day showing what's already scheduled; the user drops the new block into open space rather than using a blind picker.

Default: next open slot on the tapped day; default duration 1h with an end-time/duration control.
Quick chips: Today · Tomorrow · This weekend.
All-day toggle.
Collision detection: if the new block overlaps an existing one, that block lights up red.


Where / Who (optional) — location field (sets up travel-time/conflict awareness later) + people/notes.
Anything else? — collapsible row labeled "Reminders, location, notes". Expands to:

Reminder lead-time ("remind me X before").
The three Valo toggles (see below).


Life-area facet — single-select chip row: Personal · Health · Work · Social · Growth · Faith. This drives the color coding and replaces the old free "Type" field. "Habit" is NOT a facet — do not include it here.
Footer — Save event / Save & add another.


The three Valo toggles (live inside "Anything else?")

Have Valo check in on this — terracotta #C17B3F when on. Closes the loop so Valo can later ask "did you complete this / how did it go?" This is the toggle that changes what the screen is.
Counts toward a goal — links the item to a Big Goal so completing it advances progress. When set, show the linked-goal chip (e.g. Marathon · Oct).
Track as countdown — sets flaggedForCountdown so the item surfaces in the Countdown strip on Plan.
